# 宝贝特工

正式网站：https://bi8bo-baby-agent.netlify.app

手机优先的孕产手册：今天的安排、健康记录、动态日程和可检索的知识指南。每个人填写自己的孕程，没有预填任何人的预产期、孕周、预约或健康数据。

本期覆盖整个孕期至实际分娩后一个日历月。沿用原项目的 HTML/CSS/JavaScript、底部导航、弹层与本机存储，无需前端框架或数据库。

## 使用

1. 首次打开可按三步引导使用；“我的 → 新手使用引导”可随时重看。先在“今天 → 设置我的孕程”填写医生估算的预产期或某一天的孕周；也可从末次月经第一天粗估，之后由医生核对。不知道的资料可以留空。
2. 选择就医地区、糖尿病情况。孕前已有二型糖尿病与妊娠期糖尿病区分处理；未选地区不生成医疗窗口。
3. 底部固定为“今天、日程、饮食、指南、我的”。首页直接记血糖、体重、血压、备忘或一餐；“今天 → 全部记录”看历史并补记活动、用药等。底部“饮食”集中查看餐食与食物库；记餐在一个窗口内选食物、填份量、保存，返回选食物时保留当前已选内容。
4. “日程 → 我的产检表”先看四阶段路线、13 类检查与准备说明，再看个人日期和进度；“按天查看”在月历中选日期，汇总当天安排和记录。建议不是预约凭证，不会替你挂号，也没有后台手机通知。
5. “指南”先看产检和饮食两大入口，再用阶段/主题卡片浏览或搜索“便秘怎么办”“水果能吃吗”。原笔记入口已改成无需登录的站内整理版，公开专业资料保留外链与核验日期。
6. “我的”可保存身高、孕前体重、孕产史、胎数、血型、过敏与用药等资料和医生要求，导出/恢复备份。改日期先看影响再确认；实际分娩必须由本人确认。血压按每次测量保存，不覆盖为一个固定值。

## 数据保存、备份与旧资料

- 新资料存在当前网址、当前浏览器的 localStorage，键为 baby-agent-v2。刷新、关闭后可以读取；无账号、无上传、无自动同步。
- 换手机、浏览器、网址，不会自动带上记录。同设备多人使用时应分别使用浏览器个人资料。
- “我的 → 导出备份”下载含私人资料的 JSON 文件。新设备打开网站后用“从文件恢复”，先查看数量再确认替换。导入前自动保存本机快照，可点“恢复前快照”回退。
- 清除网站数据、无痕模式、设备损坏或浏览器清理会导致丢失。添加主屏幕不能代替备份。备份文件不加密，请保存在自己的安全位置。
- 发现旧键 health-assistant-v1 时，先下载旧资料并执行迁移。旧键保留，迁移前原文另存 health-assistant-v1-before-baby-agent。旧真实体重与备忘转换为可编辑记录，缺失时间保持为空。
- 旧饮食、活动、自建知识、食物和计划保存在“我的 → 旧版资料”。不将 GL 当血糖，不将减脂计划转成孕期治疗安排。旧业务模块留在仓库供追溯，发布包不包含停用模块。
- 读取损坏、空间不足或另一页面修改资料时，会提示失败/刷新，不显示虚假的“已保存”。

## 内容边界

8 篇得到书籍笔记已整理成 16 篇指南、4 个阶段和 9 个主题。原笔记不是医院临床路径；有冲突的数字和绝对说法未直接采用。公共科普来源来自 NIDDK、NHS、CDC、国家卫生健康委、国民健康署及 ACOG，保留出处、地区、来源更新时间（未取得时写明）与核对日期。

共有 39 个跨地区建议模板（不会全部发给一个人）：台湾包含官方 14 次建议产检与相关检查；中国大陆结合基础随访框架和已核对的筛查窗口；美国呈现已核对的项目，复诊频次由照护团队制定。基础服务次数不代表高风险孕妇的完整医疗计划。筛查按糖尿病类型过滤，不给已确诊者重复安排常规妊娠期糖尿病诊断筛查。

个人血糖目标、监测频次和治疗安排以本人录入的医生要求为准。没有自动诊断、AI 问诊、减肥热量缺口或自动调药。原库产后内容不足，已补一般照护衔接内容；未完整开发宝宝育儿模块。

饮食工具复用 186 项旧食物参考数据，可自填每份或每 100g 标签，支持 kcal/kJ 换算。旧库未逐条核验，糖含量原本缺失，不补为零。GI 不能靠食物名称或含糖量计算；GL 只有在 GI 与可利用碳水有值时估算。旧库 GL 用参考碳水作粗估并标记，组合 GI 缺资料则不计算。改食物库不改历史餐食快照，也不把 GL 当实际血糖。

## 本地开发与验证

需要 Node.js，无第三方运行依赖。

```sh
node --test tests/*.test.mjs
node scripts/build-static.mjs
node scripts/serve.mjs
```

本机预览：http://127.0.0.1:4173/ 。它只在当前电脑可访问，不能作为手机线上网址。不要双击 HTML，也不要在仓库根目录启动公开静态服务。

发布产物只在 dist/，排除 .private、测试、备份、文档和 Git 文件。Service Worker 只缓存网站资源；更新时需更改 sw.js 的 CACHE 版本。关闭所有本站标签再打开后启用完整新版，避免替换正在编辑的表单。主屏幕安装及真实设备离线行为还需上线后在目标手机实测。
