# 健康助手 Health Assistant

一个**完全本地、单人使用**的个人健康助手，做成可安装到 iPhone 主屏幕的 PWA（渐进式网页应用）：记录饮食热量、蛋白质、运动消耗和体重，自动计算每日热量缺口，用图表看趋势、做对比，按日历监控计划达标情况，还带一个随身知识库。

**所有数据只保存在你的手机本地（localStorage），没有账号、没有服务器、不联网上传。** 支持一键导出/导入 JSON 备份。

## 功能一览

- **📝 记录**
  - 每日摄入热量：可搜索内置食物库（约 190 种常见食物，含热量/蛋白质/碳水/GI 参考值和"个、碗、杯"等常用分量），输入克数自动计算；也可直接输入每餐热量
  - 餐次数量可自定义（默认早/午/晚餐，可随时加"加餐、夜宵"等）
  - 蛋白质摄入：随食物自动计算，也可直接输入克数
  - 🍬 **控糖记录**：碳水化合物摄入与血糖负荷 GL（= GI × 碳水）自动累计，搜索食物时直接显示 低/中/高GI 徽标
  - 运动消耗：内置约 30 种常见运动，按 MET × 体重 × 时长估算，也可直接输入
  - 体重与状态：想起来就记，不必每天；支持文字备注
  - 每日自动汇总：摄入 / 总消耗 / 热量缺口 / 蛋白质 / 碳水 / GL
- **📈 图表**
  - 时间维度：日、周、月、季、半年、年、2 年
  - 任选指标组合出图：摄入、总消耗、运动消耗、热量缺口、蛋白质、碳水、血糖负荷GL、体重
  - 摄入 vs 消耗双曲线对比，自动给出累计缺口、均值、总和、体重变化等结论
  - 快捷提问："过去一年体重变化？""最近一月控糖情况？"一键出图出结论
  - 每张图都有表格视图，深色模式自动适配
- **📅 计划**
  - 🎯 **目标与建议**：设定目标体重+日期或控糖目标，按你的身体数据（BMI、基础代谢、特殊状况）自动生成每日饮食与运动建议，目标过快会预警，可一键按建议创建计划
  - 自定义计划：日期范围 + 每日摄入上限 / 运动下限 / 蛋白质下限 / 碳水上限 / GL 上限 + 备注
  - 日历呈现每天达标状态（✓ 达标 / △ 部分 / ✕ 未达标）
  - 打开应用即见"今日提醒"：今天要做什么、还差多少
- **📚 知识库**
  - 🔍 **低GI食物速查**：全库食物按 低/中/高GI 筛选与搜索，日常"能不能吃"随手查
  - 内置知识：控糖与GI基础、孕期饮食运动注意、二型糖尿病饮食运动指南、减脂运动常识
  - 自建主题：按主题收藏纯文字知识，全文搜索覆盖内置+自建
- **👤 特殊状况适配**：在"我的"页选择 孕期 / 二型糖尿病 后，建议引擎针对性调整（孕期不给减重建议、糖尿病自动加控糖目标），相关知识置顶
- **💾 备份**：一键导出全部数据为 JSON 文件，随时导入恢复

## 怎么用到 iPhone 上

1. 把本仓库部署为静态网站（推荐 **GitHub Pages**，见下）
2. 在 iPhone 上用 **Safari** 打开网址
3. 点底部 **分享按钮 → 添加到主屏幕 → 添加**
4. 之后从主屏幕图标打开，全屏运行、离线可用，和普通 App 一样

> 提示：请务必"添加到主屏幕"后使用。iOS 对普通浏览器标签页的本地数据有 7 天不访问即清除的策略，而主屏幕应用不受此限制。另外建议定期在"我的 → 数据备份"里导出备份。

### 部署到 GitHub Pages

仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选仓库的默认分支、目录选 `/ (root)`，保存后一两分钟即可访问
`https://<你的用户名>.github.io/Health-Assistant/`。

### 本地预览

纯静态站点，任意静态服务器即可：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

（因为使用了 ES Modules，直接双击 index.html 以 file:// 打开无法运行，需通过 http 访问。）

## 技术说明

- 无框架、无构建、无第三方依赖：原生 HTML/CSS/JS（ES Modules）
- 图表为自绘 SVG：多系列曲线、十字准线悬浮提示、图例、表格视图、浅色/深色主题
- 数据存储：`localStorage`（键 `health-assistant-v1`），并请求持久化存储
- 离线：Service Worker 预缓存全部资源，缓存优先 + 后台自动更新
- 基础代谢按 Mifflin-St Jeor 公式计算；热量缺口 = 基础代谢 × 活动系数 + 运动消耗 − 摄入

## 数据与免责声明

食物热量/蛋白质为常见参考值（整理自《中国食物成分表》及 USDA 公开数据），运动消耗按 MET 代谢当量估算，均为估算值，仅供日常记录参考，不构成医疗建议。
