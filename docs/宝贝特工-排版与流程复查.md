2026-09-11，针对本轮三张截图调整。未部署、提交或推送，未修改用户真实健康资料。

## 已修改

- 收起引导后的 `null`：原因是原生 `Element.append` 会将传入的null转成文字。首页现在过滤空节点；增加实际点击“收起”和刷新后的文字回归检查。
- 统一正文行距1.8、标题行距、段落间隔、卡片留白、表单标签与输入框间距、按钮间距。内容以标题/正文/说明分层；手机和电脑均应用。
- 首次访问不再叠加大幅欢迎卡与引导卡，优先露出三步引导、快速记录和今天的安排。
- 底部固定为“今天 / 日程 / 饮食 / 指南 / 我的”。原记录页保留在“今天 → 全部记录”，旧地址仍可使用。首页截图中的两处跳转按钮移除，改为直接打开记餐。
- 饮食页分“餐食记录 / 食物库”。搜索、每100g营养查看、管理自定义食物集中在食物库；每日合计与知识说明可展开。不再在多个页面之间来回找食物。
- 记餐在同一个窗口内完成选食物、填份量、添加多项与保存。只有需自定义营养标签时打开辅助表单；保存后返回原餐食流程。返回选择页保留已选食物，食物库详情可以直接用该食物记餐，编辑历史资料仍可修改或删除。
- 产检总览按地区展开具体窗口，沿用原39个模板的数据和适用人群规则，没有新增医学时间规则。未选地区呈现通用步骤；阅读地区切换不改变个人地区、预约或建议。个人日期仍须修改孕程并确认后更新。
- 静态缓存更新为v7。关闭本站全部标签再打开启用新版，勿通过清除网站数据刷新界面。

时间节点再次核对了[国家卫健委2025筛查通知](https://www.nhc.gov.cn/fys/c100078/202504/ec0bce75c0884b41a2262ef84531ad88.shtml)和[国民健康署产检时间说明](https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=4809&pid=18455)。详细专业依据和限制沿用《第二轮完善》。展示粒度变化不代表增加临床检查。
