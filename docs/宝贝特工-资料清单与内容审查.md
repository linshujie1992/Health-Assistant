## 4. 原项目需要撤下或重做的功能

- `js/advice.js` 即使在孕期模式仍按普通成人代谢公式推算孕期热量，并生成蛋白质、运动消耗和 GL 目标。孕期入口应停用这类自动个体建议。
- `js/log.js` 用全天 GL 区间呈现控糖状态；GL 不是测得血糖，不能充当孕期血糖是否达标的结论。
- `js/knowledge-builtin.js` 把普通二型糖尿病减重、孕期和减脂文章并列。孕妈首页与推荐中不能直接显示普通成人减重逻辑；旧自建笔记保留在个人资料，未审查内容不混作新版指南。
- `js/store.js` 的部分汇总把缺失营养字段按零处理。新版健康趋势和完成状态必须保持空值，缺记录不算达标，也不算未达标。
- 当前计划是摄入/消耗/GL 目标清单，不是产检预约。它们保留为历史资料，不自动变成孕期计划。
